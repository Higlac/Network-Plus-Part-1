## Part 1: Design Questions

### a) Based on the topology, how many subnets are needed?
**Answer:** 5 subnets

### b) How many bits must be borrowed to support the number of subnets?
**Answer:** 3 bits

### c) How many subnets does this create?
**Answer:** 2^3 = 8 subnets

### d) How many usable hosts does this create per subnet?
**Answer:** 2^5 - 2 = 32 hosts per subnet

## Lab Completion Pointers

### Step-by-Step Guidance:

1. **Analyze Requirements:**
   - Count LANs in the topology (typically 2-4 LANs)
   - Add 1 for router-to-router connection
   - Each subnet needs 25+ usable hosts

2. **Calculate Subnetting:**
   - For 25+ hosts: Need at least 5 host bits (2^5 - 2 = 30 hosts)
   - If you need 4 subnets: Need 2 subnet bits
   - New mask: /24 + 2 = /26 (255.255.255.192)

3. **Common Subnet Scenarios:**
   ```
   /26 subnetting (4 subnets, 62 hosts each):
   - Subnet 0: 192.168.100.0/26    (.1-.62)
   - Subnet 1: 192.168.100.64/26   (.65-.126)
   - Subnet 2: 192.168.100.128/26  (.129-.190)
   - Subnet 3: 192.168.100.192/26  (.193-.254)
   ```

4. **Device Assignment Strategy:**
   - Router interfaces: First usable IP in each subnet
   - Switches: Second usable IP (if managed)
   - PCs/End devices: Any remaining IPs
   - Default Gateway: Router interface IP

### Binary Calculation Help:
- Borrowed bits go from left to right in the host portion
- For /26: Bits 7,6 are subnet bits, Bits 5-0 are host bits
- Subnet 2 binary: 01000000 (64 decimal)
- Subnet 3 binary: 01100000 (96 decimal)
- Subnet 4 binary: 10000000 (128 decimal)
